# CameraHub

A static, responsive Sony camera and photography equipment reference app for an office photography and multimedia team.

## Features
- Sony camera quick-reference specifications
- Accessories catalog with practical uses and compatibility notes
- Lens mount, battery, flash, audio, memory-card and support compatibility guide
- Local equipment inventory with add/edit/delete, search, CSV export and JSON backup

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Publish with GitHub Pages
1. Create a new repository on GitHub, for example `camerahub`.
2. Upload `index.html` and this `README.md` to the repository's root (the top level).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish. Your site URL will look like `https://YOUR-USERNAME.github.io/camerahub/`.

## Important notes
- Inventory records are stored in the browser's local storage on the device/browser where they are entered. They are not synchronized between team members and are not uploaded to GitHub.
- Use **Export CSV** for a spreadsheet or **Backup JSON** for a restorable data backup.
- The camera data is a quick-reference summary, not a substitute for the official Sony specifications. Confirm exact recording modes, card requirements, compatibility and firmware details before purchasing or production use.
- Before making the app an official office inventory, replace sample entries and confirm models/accessory compatibility against the actual equipment and official Sony documentation.
